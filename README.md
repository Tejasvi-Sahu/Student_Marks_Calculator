# Student Marks Calculator

A beginner-friendly Python project that calculates a student's
total marks, percentage, grade, and pass/fail status.

## 📌 Features

- Takes student's name
- Accepts marks for 5 subjects
- Calculates total marks
- Calculates percentage
- Automatically assigns a grade
- Displays PASS or FAIL status

## 🛠️ Technologies Used

- Python 3

## 📚 Subjects

The project currently accepts marks for:

- Maths
- Python
- DSA
- English
- COA

### Step 1: Install Python

Download Python from the official Python website.

### Step 2: Open the project

Open the project folder in VS Code.
